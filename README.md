# Yue Zhang / 张悦 — Bilingual Academic Homepage

为 GitHub Pages 准备的中英文响应式学术主页，无需安装任何软件包。

## 本地预览

直接用浏览器打开 `index.html` 即可查看。

## 发布到你的 GitHub Pages

1. 登录 [GitHub](https://github.com/)，点击右上角 **+ → New repository**。
2. Owner 选择 `Z-yyj`，Repository name 填写 `Z-yyj.github.io`。
3. 选择 **Public**；不要勾选自动添加 README、`.gitignore` 或 License，然后点击 **Create repository**。
4. 在空仓库页面点击 **uploading an existing file**。
5. 将本文件夹内的全部文件和 `assets` 文件夹拖入上传区。请上传解压后的内容，不要直接上传 ZIP 压缩包。
6. 在页面底部填写提交说明，例如 `Publish academic homepage`，点击 **Commit changes**。
7. 进入仓库的 **Settings → Pages**。
8. 在 **Build and deployment** 中选择 **Deploy from a branch**。
9. 选择 `main` 分支和 `/ (root)`，然后点击 **Save**。

通常等待数分钟后即可访问：<https://z-yyj.github.io/>
